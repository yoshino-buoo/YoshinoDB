## 后续维护

在网页「内容编辑」中，卡面「专属资料」的游戏填写 `deresute` 或 `mobamas`，按所属游戏显示能力表。星光舞台沿用 Life／Vocal／Dance／Visual；原作填写各阶段初始攻击、防御和 Cost，以及特技与双重特技附加效果。不要把等级上限、亲爱度或特训继承后的数值填进初始攻守。预览简介介绍卡面场景，具体活动和能力填入详情字段。

卡图放在 `public/assets/`，在图集中按特训前、特训后顺序登记。游戏切换、筛选和统计直接读取条目的 game 与 rarity。新增卡并不会自动从这些卡表抓取；本次为完整人工核对与收录。
